Grok Flows

Natural language workflows for X

1

Drag this to your bookmarks bar

Simply drag the button below to your browser's bookmarks bar:

Grok Flows

Or right-click → "Bookmark This Link"

2

Make sure localhost is running

This bookmarklet connects to your local dev server. Make sure it's running:

cd grok-canvas && npm run dev

Server should be running at: http://localhost:5173

3

Go to X.com and run the script

X.com blocks external scripts, so for the demo:

  1. Go to x.com
  2. Open browser console: Cmd+Option+J (Mac) or F12 (Windows)
  3. Click the button below to copy the script
  4. Paste in the console and press Enter

You'll see "Grok Flows" appear in the sidebar and a chat overlay!

4

Try some example queries

Type natural language queries in the chat:

  • "find me elon musk's most recent 10 tweets"
  • "notify me when theres 50 #crypto posts per hour"
  • "search @Tesla's latest posts"
  • "show me #AI tweets"
Note: For the demo, the bookmarklet connects to your local dev server at localhost:5173. The X API requests are proxied through the server which has the API keys configured.
